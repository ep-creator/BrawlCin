# Imagens de prévia

Renderizadas pelo próprio jogo, em resolução nativa de mundo (960x540).

- `previa-menu.png` — o menu principal.
- `previa-pausa.png` — a pausa, com a partida congelada atrás.
- `previa-fim-de-jogo.png` — o fim de campeonato, agora um menu navegável.
- `previa-confirmacao.png` — a confirmação de saída.
- `previa-transicao.png` — cinco quadros do esmaecimento entre o menu e a
  seleção, com a opacidade do quadro antigo anotada em cada um.
- `previa-controles.png` — a tela de controles, empilhada sobre o menu.
- `previa-mapa.png` — um frame como o jogador vê.
- `previa-colisao.png` — o mesmo frame com as áreas de colisão desenhadas por
  cima: vermelho é água (bloqueia), preto é grama (esconde), branco é a hitbox
  do corpo e magenta a dos pés. Serve para conferir de relance que o que se vê
  e o que colide são a mesma coisa.

São o ponto de partida para as capturas do README principal, que ainda está
pendente.
